# Kenney Art Assets

This project includes selected files from the following Kenney asset packs:

- Modular Space Kit — https://kenney.nl/assets/modular-space-kit
- UI Pack - Sci-Fi — https://kenney.nl/assets/ui-pack-sci-fi
- Particle Pack — https://kenney.nl/assets/particle-pack
- Marble Kit — https://kenney.nl/assets/marble-kit
- Pattern Pack Lines — https://kenney.nl/assets/pattern-pack-lines
- Light Masks — https://kenney.nl/assets/light-masks
- Input Prompts — https://kenney.nl/assets/input-prompts

Each pack is licensed under Creative Commons CC0 1.0. The original license text
for every pack is preserved in the adjacent `Licenses` directory. Attribution is
not required, but the project records the source URLs for provenance.

Only a curated subset of each downloaded pack is included under `Assets`. The
unmodified archives and full extracted packages are kept outside Unity's import
tree under `.art-source/kenney/` and are intentionally excluded from version
control.
