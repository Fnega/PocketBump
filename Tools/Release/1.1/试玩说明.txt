射球大战 / PocketBump 1.1 免费试玩版
开发者：Fnega

开始游戏
请完整解压整个 PocketBump1.1 文件夹，然后运行 PocketBump.exe。
不要只复制 exe：PocketBump_Data、UnityPlayer.dll 等文件必须一起保留。
支持 Windows 64 位、键盘操作、同电脑双人左右分屏，以及同一局域网双人对战。
当前没有互联网房间、匹配或中继服务。最低配置尚未完成多机型测试。

如何操作
本地双人：P1 用 WASD 移动，K 冲刺；P2 用方向键移动，主键盘数字 2 冲刺。
LAN 对战：每台电脑的本机玩家都用 WASD 和 P1 冲刺键。
可以在开始前的规则面板重新绑定冲刺键。Num2 指小键盘 2，2 指主键盘数字 2。
有效的现有绑定在同一设置配置中保留，以游戏中显示的按键为准。
按 Esc 打开比赛菜单：本地模式暂停；LAN 模式比赛继续，本机暂不接受移动/冲刺输入，角色仍可能因惯性或碰撞移动。
菜单提供继续、玩法说明、音量、打开报告目录和返回主菜单。

怎样获胜
撞击白球，把它推进对方的球门。蓝方守北门、进攻南侧橙门；橙方守南门、进攻北侧蓝门。
达到本局目标分数且领先至少 2 分时获胜。默认目标 8 分，可在开局前修改。
Dash 持续 0.3 秒，起步时确定方向，结束后冷却 3 秒；再次按键触发下一次冲刺。
没有方向输入时沿角色当前朝向冲刺。
掉出场地不给对方加分，通常 3 秒后在安全位置复活。进球后双方归位重新开球。
撞柱会短暂眩晕，头上显示“晕”。高速 Dash 可以撞碎墙；10 秒后位置空闲时修复。
绿色球：最多 5 秒撞击强化。紫色球：最多 5 秒霸体，免击退/眩晕，但仍可能掉落。掉落或进球会清除这些 Buff。
蓝色球：立即随机传送到安全位置；没有安全位置时消耗拾取但不传送。
右上角小地图显示玩家位置/朝向、白球、球门和障碍物。网络提示在右下角。

局域网连接
两台电脑必须使用同一个完整 1.1 包，并连接同一路由器/局域网。
1.1 使用协议 8，与 1.0（协议 7）不兼容；不能混用旧 exe、旧数据目录或不同版本。
主机选择 HOST LAN，另一台选择 JOIN LAN，输入主机局域网 IPv4 地址。
两边的目标分数和球数量应一致。若主机修改了规则，加入者先选择 START，设置相同分数和球数量，再选 BACK 返回，最后选 JOIN LAN。
服务端使用 UDP 7777（以项目配置为准）。127.0.0.1 仅用于同电脑测试。
本机双窗口测试：运行 PocketBump.exe 两次，一窗 HOST LAN，另一窗 JOIN LAN 并填 127.0.0.1。
Run-LanDiagnostics.ps1 面向单独的 Development 诊断包，不要用其内部测试参数驱动本正式包。
若 Windows 询问网络权限，请仅允许你信任的专用网络；无需关闭整个防火墙。
访客 Wi-Fi 或校园网络的设备隔离可能阻止连接；异地公网地址不能保证直连。

1.1 网络故障说明
本次修复区分对方主动离开、自己超时与对方报告故障，并记录接收错误及故障前约 20 秒的采样时间线。
正常返回主菜单仍显示 PEER LEFT。对方报告故障时显示对方故障原因；通知包也可能丢失，此时本机会独立超时。
临时等待可能恢复；终止故障时画面保持冻结，打开报告目录保存双方证据，然后返回菜单重新连接。
五秒超时策略、比赛规则和回滚窗口保持不变，没有新增自动重连。
1.0 的校园网中断根因尚未确认；1.1 改进故障归因和证据，不能据此保证校园网不会再次中断。

设置与反馈
默认小窗 1280×720，可切换全屏/窗口；音效音量可以调至 0 静音。
非 16:9 屏幕全屏时可能出现上下黑边，以保持画面比例。
1.1 继续使用 Fnega/PocketBump 设置与报告目录，旧版本报告不会被删除或改写。
网络报告仅保存到本机，不自动上传。菜单“打开报告目录”可打开文件夹。
默认目录：%USERPROFILE%\AppData\LocalLow\Fnega\PocketBump\NetworkReports
报告可能包含局域网端点、比赛进度、接收错误和时间线；由你主动选择文件分享给试玩包提供者。
发生故障后请保留双方相同时段的 JSON、截图、版本号、build_guid、连接方式和复现步骤。
请不要只交一边报告；双方证据才能对照谁先发生故障。Player.log 在上述目录的上一级。
