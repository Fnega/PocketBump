PocketBump 1.0 真实双电脑验收（由试玩者执行）

使用同一个完整压缩包，两台 Windows 电脑连接同一个局域网。
对照 build-info.json 的 build_guid，并保留双方产生的 NetworkReports。

1. A 主机、B 加入：完成至少一场达到胜利条件的比赛，检查双方比分/胜者一致。
2. 连续选择重赛至少 3 次，双方均进入下一局；尝试一方先同意、另一方稍后同意。
3. 测试 Dash、撞球、绿/蓝/紫 Buff、掉落复活、撞柱眩晕、碎墙及修复。
4. LAN 比赛中按 Esc：说明应提示比赛继续；退出菜单后恢复控制，不出现积攒的冲刺。
5. A 返回主菜单，B 显示对方离开；重新建房并加入。再交换角色重复一次。
6. 连续玩 20–30 分钟，记录是否出现 DESYNC、异常停顿、无提示跳菜单或黑屏。
7. 两边打开报告目录，把对应时段的 JSON 和必要的 Player.log 一起交回检查。

记录：电脑/系统、连接方式（有线或 Wi-Fi）、版本/build_guid、开始时间、结果、问题复现步骤。
在双方报告被检查前，此项应保持“待人工双电脑验收”，不能以本机双窗口结果替代。
