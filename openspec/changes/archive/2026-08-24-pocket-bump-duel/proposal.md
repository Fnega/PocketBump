## Why

工程几乎是空的 2D 项目，需要一款体量小、规则一眼能懂、靠碰撞而不是解谜的双人对打。先做同机双人把桌子和短局循环做爽，联机放到后续，避免物理同步把第一版体积撑爆。

## What Changes

- 新增一张四人字形口袋的 2D 物理桌：上下口只吃得分珠、左右口只吃人。
- 新增同机双人对打：两人各守一端，把珠打进**对面的袋**得分；人掉进左右通杀口则对面得分。
- 新增短局循环：任意一次得分即结束本局、重置场景、3 秒半场热身后开门再出珠。
- 新增胜负：达到获胜分且领先 2 分者获胜。获胜分与每局珠数可在设置里调整（默认 8 分、1 颗珠）。
- 本变更不包含联机、大厅、匹配或主机权威同步。

## Capabilities

### New Capabilities

- `arena-pockets`: 桌子几何、中线闸门、四口袋碰撞过滤、得分珠与玩家刚体在桌上的物理互动。
- `match-flow`: 开球倒计时、得分判定、局重置、领先 2 分的胜负、获胜分与珠数设置。
- `local-two-player`: 同机两套操作、出生站位、摄像机与比分/倒计时反馈。

### Modified Capabilities

- （无。仓库尚无主规格。）

## Impact

- 主要改动在 `Assets/` 下的场景、玩法脚本与少量 UI；当前仅有 URP 2D 空场景。
- 使用现有 `Physics2D`，不新增联网包。
- 不影响已装的 MCP 包；不改 Package Manager 依赖（除非实现中发现 2D 物理/输入缺模块，再单独立项）。
