# Dash 碰撞灰盒实施记录

2026-10-02，变更 `redesign-dash-collision-arena`。下文保留首次独立灰盒交付时的历史记录；交付后用户回复“可以就这样”，手感/布局已接受。随后固定的生产配置及新增验证见文末，不把历史灰盒报告改写为新版验证。实际机器人美术 G3 仍未验收。

## 范围与入口

- 新核心：`ArenaRulesProfile`、`ArenaGeometry`/`ArenaRandom`、`DashArenaInput`、`DashArenaState`、`DashArenaSimulation`。
- 新预览：`DashArenaGreybox` 和显式 `DashArenaGreyboxBaker`。一个模拟、两个同向倾斜跟随相机、一个 AudioListener，显示几何不承担权威物理。
- 预览目标场景：`Assets/Scenes/DashArenaGreybox.unity`。生成/渲染的最终成功证据见本文件后续记录。
- 试玩入口：Unity `Tools > Pocket Bump > Greybox > Open Isolated Preview`，再点 Play。左边 WASD + K，右边方向键 + 数字 2；画面上的 `Restart preview` 重新开始。必须只打开此独立场景，不与原 Arena 叠加运行。
- 蓝色提示非模态，绿色/紫色按 5 秒显示，修复等待有琥珀轮廓，晕标记限制在个人视口。键位和 UI 是灰盒临时入口，尚非正式设置迁移。

正式 `MainMenu.unity`、`Arena.unity`、v6 的 `MatchDirector`/`MatchSim`/协议和 Build Settings 均不接入灰盒。本轮未删除旧持球/Boost/Shoot 的生产路径，因此正式旧版仍保持旧玩法；对应迁移任务不能因灰盒已有新动作就标记完成。

## 已确认与临时参数

已按用户确认采用 48×72 场地、9.675 侧向死亡口、18 Tick Dash、结束/打断后 180 Tick 冷却、36 Tick 柱晕、180 Tick 独立复活、600 Tick 墙修复、绿紫各 300 Tick、绿额外冲量 1.5 倍、600 Tick 生成一个 Buff/最多三个。

暂定手感：普通速度 12，Dash 24，无阻挡 Dash 位移 7.2；球速上限 48；普通/冲刺撞球额外速度冲量 4/12，玩家互撞额外速度冲量 6/14，墙法向碎裂阈值 18。所有单位为模拟单位及秒。`IsProvisional=true`，没有冻结生产数值。

第二次量化后把临时外力上限从 36 调整为 72：36 会在 Dash 对撞中提前饱和，抹掉绿色增强。该调整不改变已批准的时长/倍率，并有逐项数值断言约束；最终轻重仍由用户试玩确认。
